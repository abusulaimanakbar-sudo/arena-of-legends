# Arena of Legends

Game MOBA 5v5 gaya Mobile Legends / Honor of Kings, dibuat dengan Godot 4.7 (3D, aset CC0: Quaternius, ambientCG, Poly Haven).

## Pasang di Android
1. Unduh `AOL.apk` dari halaman **Releases** dan pasang (izinkan "pasang dari sumber tidak dikenal").
2. Saat pertama dibuka, game mengunduh paket data (~190 MB) dari rilis ini. Gunakan Wi-Fi.
3. Pilih hero, ban/pick, lalu main. Tap tanah untuk bergerak/menyerang, tombol Q W E R untuk skill.

File rilis: `AOL.apk` (kecil, kode saja), `content_1.0.0.pck` (aset), `manifest.json` (alamat dan hash paket data).
