# Vario 150 LED — Garage & Racing Simulator

Game web 3D (Three.js). Garasi: ganti bore up, noken as, throttle body, filter, knalpot, roller/per CVT, ban, warna.
ECU: timing, AFR, idle, limiter, pop & crackle. Suara dibuat dari 2 rekaman asli (idle & jalan) + preset
(Standar, Racing, Brong, **Timing Kuda**, Cempreng, Scream) dan slider manual. Lalu **Tes Jalan** di sirkuit kota.

Jalankan: `python3 -m http.server 8000 --directory vario150-sim` lalu buka http://localhost:8000
Kontrol: W/↑ gas, S/↓/Spasi rem, A D/←→ belok, C kamera, R reset, G garasi. Di HP ada tombol layar.
